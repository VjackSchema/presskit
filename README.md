# Vjack Schema press kit

Shareable static DJ portfolio for Vjack Schema. It needs no build step or dependencies.

## Run locally

```sh
npm run dev
```

Then open http://localhost:4173. The page is responsive and can be saved to PDF from the browser print dialog.

## Publish free with GitHub Pages

Create a public GitHub repository, upload this folder, then open the repository's **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/ (root)`, and save. GitHub will provide the public URL.

## Replace the portrait

Replace the `.portrait` placeholder in `index.html` with an `<img>` using a high-resolution press photo. Update the Open Graph image metadata once a hosted photo is available.
